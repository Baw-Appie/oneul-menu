# GPT-6 Luna 자연어 검색

## 모델과 사용 범위

사용자가 확인한 모델은 `gpt-6-luna`다. 처음 요청한 “GPT-6.1 Luna”와 공식 모델명이 달라 확인 후 진행했다. 다른 모델로 자동 대체하지 않는다.

기존 브라우저 UI는 정적 파일로 유지하고, 로컬 Node.js 서버에 `/api/search`를 추가했다. `package.json`과 런타임 의존성을 추가하지 않았다. GitHub Pages는 API 서버를 실행하지 않으므로 공개 데모에서는 기본 검색이 유지되고 AI 연결 준비 안내가 나온다.

## 로컬 실행

1. `.env.example`을 프로젝트 루트의 `.env`로 복사한다.
2. 편집기로 `.env`에 아래 값을 설정한다. 실제 키를 README·소스·채팅에 넣지 않는다.

```dotenv
OPENAI_API_KEY=여기에_실제_OpenAI_API_키
```

3. 프로젝트 디렉터리에서 실행한다. `--env-file`을 지원하는 Node.js 20.6 이상이 필요하다.

```bash
node --env-file=.env server.mjs
```

이미 실행하는 셸의 환경 변수에 키를 설정했다면 기존처럼 `node server.mjs`로 실행한다. 서버를 실행한 뒤 키를 변경했다면 서버를 재시작해야 한다.

4. `http://127.0.0.1:4173`에서 다음과 같은 문장을 입력하고 **AI로 메뉴 찾기**를 누른다.

- “만원 이하로 맵지 않은 국물 요리”
- “7천원 안에서 간단하게 먹을 음식”
- “매콤한 음식이 먹고 싶은데 면 요리는 빼줘”

예시 문장 버튼은 입력만 채운다. 검색 버튼을 누르기 전에는 API를 호출하지 않는다. OpenAI API 사용 요금은 사용자의 API 계정에 적용된다.

## 검색 동작

- 현재 종류·예산·매운맛·일반 검색어·제외·즐겨찾기·최근 먹은 메뉴 제외 조건으로 후보를 먼저 만든다.
- 검색 문장과 해당 후보의 정보만 서버에서 OpenAI Responses API로 보낸다. 선택 기록은 전송하지 않는다.
- 모델은 관련 메뉴 ID, 짧은 설명, 최대 금액, 허용 매운맛을 구조화된 JSON으로 반환한다.
- 서버는 ID·자료형·중복·설명 길이를 검증하고 금액과 매운맛을 다시 적용한다. 후보 밖 메뉴를 반환한 응답은 오류 처리한다.
- 결과 카드는 적합도순으로 표시한다. 랜덤 추천은 같은 결과 집합에서 무작위로 선택한다.
- 검색어나 필터·제외·즐겨찾기 상태를 바꾸거나 기록을 추가·삭제하면 기존 AI 결과와 진행 중 요청을 무효화한다. 로컬 날짜가 바뀌었을 때도 최근 기간에 맞춰 무효화한다.
- 메뉴 카드·무작위 추천·두 메뉴 비교는 같은 AI 결과 집합을 사용한다. 즐겨찾기 목록과 선택 기록 자체는 서버에 보내지 않는다.
- AI 검색 해제를 누르면 기존 조건 검색으로 돌아간다. AI 검색 결과·문장은 브라우저 저장소에 저장하지 않는다.
- API 오류·취소·시간 초과 시 기존 메뉴 기능을 계속 사용할 수 있다. 모델을 호출하지 않고 AI 결과인 것처럼 표시하는 대체 동작은 없다.

## 키와 요청 처리

- 키는 서버 환경 변수에서만 읽으며 HTML·브라우저 JavaScript·응답에 포함하지 않는다.
- `.env`와 `.env.*`는 Git에서 제외하고 빈 `.env.example`만 추적한다. 정적 서버도 해당 파일을 제공하지 않는다.
- 일반 실행은 `127.0.0.1`에 바인딩하고, `HOST` 환경변수로 변경할 수 있다. API의 Host·Origin·Fetch Metadata를 검사하고 JSON POST만 허용한다. 배포 시 `APP_ORIGIN`으로 실제 HTTP/HTTPS 접속 주소를 지정한다.
- 입력은 500자, 본문은 8KiB로 제한한다. 동시 요청 2개, 분당 6개, 최근 1시간 60개 제한을 서버 메모리에서 적용한다. 재시작하면 초기화된다.
- OpenAI 호출은 20초, 브라우저 대기는 25초로 제한한다. 브라우저 취소 후에도 이미 전송된 모델 호출은 완료되어 요금이 발생할 수 있다.
- `store: false`로 응답 저장을 비활성화한다. 이것이 모든 서비스 측 로그·보존이 없음을 뜻하지는 않는다.
- 공급자의 원본 오류·키·문장을 서버 로그에 출력하지 않는다.
- Docker 실행과 도메인 설정은 [배포 안내](DEPLOYMENT.md)를 참고한다. API 키를 설정한 공개 서비스에는 별도의 인증·영속 사용량 제한이 필요하다.

## 정확성 한계

자연어의 의미 해석은 모델이 수행하므로 항상 정확하다고 보장하지 않는다. 예시 가격과 메뉴 설명을 기반으로 검색하며, 식당별 실제 재료·알레르기·영양 정보를 판정하지 않는다. 해당 정보가 필요한 요청에는 확인 필요 안내를 하도록 구성했다.
