## 저장 실패 경로: 2개 모의 환경 통과

실제 앱 모듈을 최소 DOM·저장소 모의 환경에서 실행했다. 실제 브라우저 저장소를 강제로 차단한 검증은 아니다.

- 손상된 JSON: 초기 메뉴 30개 표시, 불러오기 실패 안내, 이후 분식 필터 4개 표시.
- 저장소 읽기 차단 및 쓰기 예외: 앱 실행 유지, 필터 동작, 저장 불가 안내 표시.

## 실제 브라우저 흐름

- 한식·10,000원·순한맛 선택 후 예상 메뉴 3개 표시.
- 추천 결과가 후보 안에 있으며, 재추천 시 직전 메뉴와 달라짐.
- Escape로 추천을 취소하면 기록이 증가하지 않음.
- 불고기 덮밥 두 번 확정 후 기록은 1개, 중복 안내 표시.
- 새로고침 후 필터 3개와 기록 1개 복원.
- 검색으로 1개 후보만 남기면 재추천 버튼 비활성화.
- 그 후보를 제외하면 빈 결과 안내 및 추천 버튼 비활성화.
- 제외 목록에서 복원하면 다시 후보에 포함.
- 새로 추가한 빈 결과의 직접 복원 버튼으로 후보 1개 복구.
- 기록 2개 중 1개 삭제 후 남은 삭제 버튼의 `tabindex=-1` 문제 발견. 수정 후 `tabindex`가 없는 기본 버튼으로 유지되는 것을 확인.
- 375 × 812 화면에서 문서 너비 375px, 1280 × 1000 화면에서 문서 너비 1280px: 가로 넘침 없음.
- 모바일에서 분식·7,000원·순한맛 선택 → 김밥·찐만두 표시. Enter로 추천 창 열기 및 Escape로 닫기 확인.
- 브라우저에서 수집된 error/warn 로그 없음.
- 검증용으로 생성한 선택 기록은 UI에서 삭제하고 필터를 초기 상태로 복구.

## 미리보기 서버와 공개 배포

로컬 미리보기 서버의 변경 후 `/`와 `/src/core.mjs`는 HTTP 200, 인코딩된 상위 경로를 이용한 `.git/config` 요청은 HTTP 404임을 확인했다.

GitHub API에서 `Baw-Appie/oneul-menu`의 공개 범위가 `PUBLIC`, Pages 상태가 `built`임을 확인했다. 공개 주소 `https://baw-appie.github.io/oneul-menu/`를 브라우저에서 열고 한식·10,000원·순한맛 조건으로 추천을 실행해 돼지국밥과 해당 조건 표시를 확인했다. 공개 주소에서 수집된 error/warn 로그도 없었다. 이후 필터를 초기화했다.

4. Responses API 형식의 응답 파싱

8. 공급자 401/403/404/429/500 오류를 안전한 안내로 변환

10. 거절·불완전한 응답을 성공으로 표시하지 않음

16. 본문 크기·Content-Type·잘못된 JSON·분당 요청 제한

### 실제 GPT-6 Luna 호출 4회

사용자가 프로젝트 `.env`에 키를 설정한 뒤 `node --env-file=.env server.mjs`로 실행했다. 키 값은 확인하거나 출력하지 않았다.

| 실행 | 입력·조건 | 브라우저에서 확인한 결과 |
| --- | --- | --- |
| 1 | 전체 종류, “만원 이하로 맵지 않은 따뜻한 국물 요리” | 쌀국수·돼지국밥·우동. 무작위 추천도 이 집합 안의 돼지국밥 |
| 2 | 한식 필터 추가, 같은 문장 | 돼지국밥 1개. 필터 변경 시 기존 AI 결과 해제 확인 |
| 3 | 한식 필터, “10원 이하로 먹을 수 있는 메뉴” | 결과 0개, 빈 결과 안내, 무작위 추천 비활성화 |
| 4 | 375px 모바일 화면, 첫 문장을 Enter로 검색 | 돼지국밥 1개. 입력·버튼 가로 넘침 없음 |

키 미설정 시 검색 버튼 비활성화와 기존 메뉴 30개 표시를 브라우저에서 확인했다. `.env`는 Git 무시 대상이며, HTTP 요청 시 `.env`와 `server/ai-search.mjs` 모두 404를 확인했다. 결과 화면은 `screenshots/ai-search-result.jpg`, 모바일 화면은 `screenshots/ai-search-mobile.jpg`에 보존했다.

AI 상태 초기화가 카드 목록을 다시 그리기 전에 제외 버튼의 순서를 보존하도록 수정했다. 최신 코드를 새로고침한 뒤 김치찌개를 제외했을 때 다음 카드인 불고기 덮밥의 제외 버튼으로 초점이 이동하는 것을 확인하고, 검증용 제외 상태는 복원했다.

## 공통 한계

- Chrome·Safari·Firefox 각각에 대한 별도 교차 검증과 실제 휴대폰 검증은 하지 않았다.
