# 오늘 뭐 먹지? — PRD v2

작성일: 2026-10-26. 기존 실습을 이어 붙이지 않고 시작하는 중간고사 프로젝트.

## 1. 소개와 목적

식사 메뉴를 고를 때 반복되는 고민을 줄이는 한국어 웹앱이다. 음식 종류, 예산, 매운맛으로 후보를 줄인 뒤 무작위 추천을 받고 실제로 고른 메뉴를 기록한다.

## 2. 사용자와 환경

- 주 사용자: 점심·저녁 메뉴를 쉽게 결정하고 싶은 대학생.
- 대표 상황: 수업이 끝난 뒤 1만 원 안에서 맵지 않은 메뉴를 고르려 한다.
- PC와 모바일의 최신 브라우저에서 사용한다. 회원가입은 없다.

## 3. 필수 기능

- F1: 30개 메뉴를 카드로 표시하고 이름·설명 검색 및 음식 종류별 탐색을 제공한다.
- F2: 최대 예산, 매운맛 조건을 함께 적용한다. 메뉴별 제외 및 제외 해제를 제공한다.
- F3: 조건에 맞는 후보 중 하나를 무작위 추천한다. 여러 후보가 있으면 바로 직전 추천을 피한다. 후보가 없으면 조건 조정을 안내한다.
- F4: 추천 결과 또는 메뉴 카드에서 오늘 먹을 메뉴를 선택하고, 최근 선택 내역을 저장·삭제할 수 있다.
- F5: 필터, 제외 메뉴, 최근 기록을 브라우저에 저장하고 다시 방문했을 때 복원한다.
- F6: 키보드 조작, 모바일 화면, 결과 안내, 저장 실패 안내를 지원한다.
- F7: 자연어 문장을 GPT-6 Luna(`gpt-6-luna`)가 해석해 현재 조건을 만족하는 메뉴에서 관련 결과를 찾는다. 문장과 현재 후보만 전송하고 선택 기록은 전송하지 않는다.
- F8: 검색 중 상태, 취소, 빈 결과, 연결 실패를 안내한다. 조건이나 입력을 바꾸면 이전 응답이 새 화면을 덮어쓰지 않는다. AI 검색 결과는 저장하지 않는다.

## 4. 화면과 디자인

크림색 배경, 주황색 포인트, 어두운 갈색 텍스트를 사용한다. 상단 탐색, 서비스 소개, 조건 선택, 추천 버튼, 메뉴 카드, 기록 영역 순으로 구성한다. 결과는 대화상자로 표시한다. 외부 이미지와 폰트에 의존하지 않는다.

## 5. 기술과 데이터

- HTML, CSS, JavaScript ES modules. 빌드와 의존성 설치가 필요 없는 정적 앱.
- 로컬 미리보기: Node.js 20 이상에서 `node server.mjs`.
- GitHub Pages 등 정적 호스팅에서 실행 가능하다.
- v2 추가: 로컬 Node 서버가 `/api/search`에서 OpenAI Responses API를 호출한다. 키는 서버 환경 변수 `OPENAI_API_KEY`로만 읽는다. GitHub Pages에서는 기존 기능을 제공하고 AI 검색은 연결 준비 상태로 안내한다.
- 가격과 메뉴 설명은 시연용으로 직접 작성한 예시 데이터다. 실시간 식당 가격이나 영양·알레르기 정보를 제공하지 않는다.
- 저장 위치는 현재 브라우저의 localStorage다. 다른 기기와 동기화하지 않는다.

## 6. 범위 제외

식당 지도, 위치 정보, 배달 주문, 결제, 회원가입, 실시간 가격, 다른 사용자와 기록 공유는 구현하지 않는다. AI API는 2026-10-26 사용자 요청으로 범위에 추가했다. 이번 단계의 서버 실행 범위는 로컬이다.

## 7. 완성 기준

- 검색·종류·예산·매운맛·제외 조건을 동시에 만족하는 카드와 후보 수가 표시된다.
- 추천은 후보 집합을 벗어나지 않고 후보가 0개 또는 1개일 때도 정상 동작한다.
- 확정해야 기록에 추가된다. 같은 날짜에 같은 메뉴를 반복 확정해도 중복 기록하지 않는다.
- 새로고침 후 필터·제외·기록이 복원된다. 손상된 저장값은 검증하여 앱 실행을 유지한다.
- 375px 모바일 화면에서 가로 넘침 없이 주요 기능을 쓸 수 있다.
- 실제 확인 결과와 한계를 문서에 남긴다.
- README에 소개, PRD·Todo, Todo 변경 내역, SKILL.md와 사용 사례, 회고 초안을 포함한다.
- 작업 단위별 실제 커밋을 남기고 GitHub Public 저장소에 올린다.

## 8. 결정 사항

가격은 정확한 판매가 대신 시연용 예상 금액으로 표시한다. 최근 기록은 최대 30건으로 제한한다. 초기 계획 원본은 첫 커밋에 보존하며 이후 변경 이유는 `TODO.md`에 기록한다.
