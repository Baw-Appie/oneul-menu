# 오늘 뭐 먹지? 🍽️

음식 종류와 예산, 매운맛으로 후보를 줄이고 오늘 먹을 메뉴를 고르는 웹앱입니다.

> 인공지능프로그래밍 중간고사 · 신규 프로젝트 · 개발 중

## 1. 제작한 것 소개

반복되는 메뉴 선택의 고민을 줄이는 것이 목표입니다. 한국어 PC·모바일 브라우저에서 사용하는 정적 웹앱으로 제작합니다. 가격은 예시 금액이며 실제 판매가와 다를 수 있습니다.

## 4. 스킬

직접 작성한 [meal-picker-review](skills/meal-picker-review/SKILL.md)를 사용합니다. 메뉴 필터의 경계값, 추천 후보의 일관성, 로컬 날짜 기준 기록과 저장 복원을 반복 확인하기 위해 만들었습니다. 개발 후 실제 적용 사례와 전문을 이 README에 정리합니다.
